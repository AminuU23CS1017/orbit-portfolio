# Orbit — Personal Portfolio

An interactive personal portfolio introducing the developer, skills, projects and contact details.

Hosted version: https://orbit-personal-portfolio-a7n11.ayomideaminu.chatgpt.site

The existing hosted version requires owner access. This repository shares the source code; it does not change access to the hosted site.

## Run locally

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000. No build step is required.
